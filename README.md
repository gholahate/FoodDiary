# FoodDiary — дневник питания (Android, Kotlin Multiplatform)

Личный дневник питания: база продуктов с КБЖУ (в том числе составные блюда и бытовые меры), дневной учёт,
цели, недельная шкала, графики, сканирование штрихкодов (Open Food Facts), резервная копия.

- **HANDOFF.md** — актуальное описание проекта, решений и договорённостей (главный документ).
- **RELEASING.md** — как выпускать версии через GitHub и как перейти на рабочую версию.
- Сборка: Android Studio, Gradle JDK 21; из терминала `./gradlew :androidApp:assembleDebug`.

Ниже — исходное описание первой версии (MVP), местами устарело.

# Дневник питания — MVP (шаги 1–7 из плана)

## Что готово

- **Схема БД (SQLDelight)**: `Product`, `ProductComposition`, `ProductUnit`, `UserProfile`, `DiaryEntry` — см. `shared/src/commonMain/sqldelight/com/fooddiary/db/`.
- **Доменные модели и расчёт составных продуктов**, включая защиту от циклов и рекурсивный пересчёт КБЖУ произвольной глубины — `shared/.../domain/CompositionCalculator.kt`.
- **Репозитории** поверх SQLDelight, скрытые за интерфейсами (`ProductRepository`, `DiaryRepository`, `UserProfileRepository`) — готово к будущей замене на реализацию с облачной синхронизацией без переписывания UI.
- **Use-case**: добавление в дневник (`AddDiaryEntryUseCase`), сохранение продукта с проверкой циклов и пересчётом (`SaveProductUseCase`), недельная/дневная статистика (`GetStatsUseCase`).
- **Заготовка под AI-поиск продуктов** (`ProductLookupProvider` + `LocalDbLookupProvider` — рабочая локальная реализация).
- **Android UI**:
  - Нижняя навигация на 5 вкладок.
  - Общий переиспользуемый слой `ui/diary/` (`DiaryDayViewModel` + `DiaryDayContent`) — один и тот же движок «дневник за один день» используется экранами «Сегодня» и «История».
  - Экран «Сегодня»: поиск, два поля (дневник/каталог), итоги КБЖУ с прогресс-барами, мини-график недели, FAB «добавить продукт», кнопка «Изм.» на карточке продукта.
  - Экран создания/редактирования продукта: переключатель «вручную» / «считать из состава», рекурсивный подбор ингредиентов, бытовые единицы измерения, проверка циклов и пересчёт КБЖУ при сохранении.
  - Экран «Профиль»: отдельный переключатель для каждого из 4 параметров КБЖУ, реактивно отражается на прогресс-барах.
  - Экран «История»: календарная сетка на месяц, под ней — полностью рабочий и редактируемый дневник выбранного дня.
  - **Экран «Графики»**: выбор параметра (калории/белки/жиры/углеводы), выбор шага (день / неделя — сумма за неделю), пресеты периода (7/30/90 дней), горизонтально прокручиваемая столбчатая диаграмма с подписями значений и дат.
  - Вкладка «Настройки» — пока заглушка.

## Как открыть и собрать

1. Установите **Android Studio** (Koala/2024.1 или новее — поддерживает KMP-плагин из коробки).
2. File → Open → выберите папку `FoodDiary`.
3. Studio подтянет Gradle-зависимости автоматически (нужен интернет — репозитории `google()`, `mavenCentral()`).
4. Выберите конфигурацию запуска `androidApp` и эмулятор/устройство → Run.

> Стек использует **Kotlin 2.0.21** и **Compose Multiplatform 1.7.0** — плагин `org.jetbrains.kotlin.plugin.compose` существует только начиная с Kotlin 2.0, так что более старые версии здесь не подойдут.
>
> Оба модуля (`shared`, `androidApp`) зафиксированы на **JVM target 21** через `kotlin { jvmToolchain(21) }` — если у вас установлен другой JDK по умолчанию и Gradle ругается на toolchain, либо поставьте JDK 21, либо поменяйте `21` на вашу версию в обоих `build.gradle.kts` (и `jvmToolchain(...)`, и `JavaVersion.VERSION_...` должны совпадать).

Первый запуск создаст пустую локальную БД `fooddiary.db` на устройстве. Рекомендуемый порядок первого знакомства: зайдите в «Профиль», включите хотя бы один параметр и задайте цель → на «Сегодня» нажмите «+», создайте пару «сырых» продуктов вручную → создайте составной продукт из них → добавьте что-то в дневник за несколько разных дней через «История» → откройте «Графики» и посмотрите на динамику.
